# justfile-recipes
Personal justfile recipes based on Universal Blue

1. You should `mkdir -p ~/.config/just`, then copy all of these files there.
2. Move the justfile up one level to ~/.config.
3. You may need to `brew install just fzf`
4. Make an alias in ~/.bashrc:   `alias mjust="just --justfile ~/.config/justfile"`
5. Running `mjust` will bring up a "chooser" by default, or you can use specific commands like `mjust update`
